# Terrain v2: final verification boundary

`final-verification.json` records the fully tested production commit, exact bundle identity, final scene metrics and actual final 1800-second NPC diagnostics. `node-tests-final.log` is the authoritative 835/835, zero-skip full run; check/build logs passed. Later portability changes affect only the render test harness, not game code, and have their own six-test passing log. The explicit absent-optional-runtime check reports six skips; it is not counted as geometry acceptance.

The earlier data/integration/landscape checkpoints and first full test failure archive are retained as historical development evidence, not substituted for final results. The initial full run failed eight old extraction/mock fixtures after the production integration; targeted repairs and a fresh complete run follow it. `junction-height-counterexample.json` plus the exact earlier network fixture preserve the real 37cm non-bridge intersection defect, now tested at zero across overlapping road widths and lanes. The below-pier water regression likewise exercises actual production motion.

`cpu-driving-geometry.png` is an offline, flat-colour projection of actual Three r128 meshes with the stationary FPV eye basis. It does not reproduce native WebGL rasterization, textures, cockpit, weather or UI, and cannot certify phone performance. All road/terrain render triangles and collision support are checked against the same Float32 source; tilted guardrails are checked against the actual thin collision strip. Static scene budget measurements are not measured draw calls or FPS.

Reproduce: `npm test`, `npm run check`, `npm run build`. Supply the official production Three r128 build through `ROADSTER_THREE_RUNTIME` (default `/tmp/roadster-three.min.js`) for optional real-geometry tests; its SHA-256 is in the final report. `node verification/coast-terrain-v2/render-study.mjs` and `python3 verification/coast-terrain-v2/render-study.py` regenerate the CPU sheet. No new runtime assets, services, lights or credentials were added.
